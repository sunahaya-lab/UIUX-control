# 夜郵局：カード編成UI

[比較と操作デモ](https://sunahaya-lab.github.io/UIUX-control/examples/night-post/)

装飾・情報密度と、選択・比較・編成の分かりやすさを両立するための制作例。既存作品のキャラクター・ロゴ・画面を複製していません。

## 条件

- 共通の依頼文 `common-brief.txt`、6枚のカード `cards.json`、生成人物画 `assets/couriers.png`。
- 未使用版：新しい履歴の別エージェント、スキル本文・他版・監査結果を参照せず制作。
- 改訂版：別の新しい履歴、UIUX-controlのSKILL.md、references/ux.md、references/composition.mdを使用。
- モデル・推論設定の上書きなし。共通の実行指示・モデル既有知識は残る。親は素材生成と比較ページ、検証、公開を担当。
- 初回はどちらも実装1回と構文確認。その後の修正はverification.jsonに記録。差分を見せるために未使用版を悪化させない。
- 各1例。人間の理解度・作業時間・好み、他のモデルや試行への一般化は未検証。

## 素材

人物画は組込みimagegenで生成した共通素材。CSSで左右中央の人物を切り出して使用。6枚は3人それぞれの2種のカードです。素材そのものの魅力と、配置・操作設計の効果を混同しないでください。

生成指示：オリジナルの幻想都市の夜間配達人3人を横に並べた一枚のキービジュアル。左に銀髪で青緑のスカーフと封書の女性、中央に眼鏡・赤錆色コート・機械のカラスの男性、右に紫髪・眼鏡・生成りコート・鍵を持つ書庫番の女性。インク線と絵画的な質感、木炭色・羊皮紙・青緑・朱色、月図と切手の背景。人物の顔を上部に分離し、文字・UI・既存作品の人物を入れない。

## 確認範囲

操作と表示の結果は `verification.json`。端末サイズの模擬確認を実機確認とは扱いません。ゲーム本編や実保存は実装していません。

## 今回の改訂

適用版は初稿のPC1440×1000で文書高1238pxとなり、編成欄が表示外に出ました。三列の等しいパネル構成も目的の表現に不足していたため、親が観察を伝えて1回再設計しました。改訂後の同条件では文書高1000px、確定ボタン下端約910pxです。未使用版は初稿のまま。したがってこの組は、同一回数の生成によるスキル単独比較ではありません。

原文の生成プロンプトは [asset-prompt.txt](asset-prompt.txt)。
