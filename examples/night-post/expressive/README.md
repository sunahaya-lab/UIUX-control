# 夜郵局・演出版

[新版を操作](https://sunahaya-lab.github.io/UIUX-control/examples/night-post/expressive/) · [前版と触り比べる](https://sunahaya-lab.github.io/UIUX-control/examples/night-post/compare.html)

前版のカード情報・初期編成・コスト上限を保ち、構図と選択→比較→配置を作り直したUIデモ。前版applied/と未使用版baseline/のファイルは変更していません。

## 試す操作

1. 鍵守便・ミラを選ぶ。人物と名前、カードの選択表示が変わる。
2. 枠2のレオンを選び「配置先と比較」。配置前の値と差、配置後コストが同じ領域に出る。
3. 枠2へ入れ替える。編成は即時更新し、カードの移動と短い印を表示する。途中で次の操作もできる。

比較ページの「両版を初期化して操作例を再生」でも同じ流れを確認できます。手動で画面を操作すると再生は停止します。切替ボタンでは両版それぞれの編成を保持します。

## 素材と演出

- [production.json](production.json)：生成前の素材リストと状態設計。
- [prompts.json](prompts.json)：組込みimagegenへ渡した生成指示。前版の集合画を参照し、3人の透過立ち絵と独立した背景を制作。
- 可変文字・数値・反転・移動はHTML/CSS/JavaScript。画像に操作を焼き込んでいません。
- 選択反転120ms、人物切替230ms、比較表示180ms、配置移動360ms、印650ms。入力と編成更新は演出完了を待ちません。OSまたは画面内の動き軽減設定では移動を止めます。
- 素材は合計約11.74MiB。低速回線での読込性能は未検証です。画像が読めなくてもラベルと編成操作を保持します。

## 検証

[verification.json](verification.json)に確認結果。Nodeのモデルテスト11件、PCと狭幅の操作、比較ページの再生・中断を確認。実機・Safari・読み上げ・200%文字拡大・人間の快適さの評価は未実施。

構図・素材・演出を一緒に変更しており、スキル単独の効果測定ではありません。戦闘・音声・保存は実装していません。
