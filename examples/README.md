# 制作条件と検証範囲

## 作り方

スキル未使用版は別の独立エージェントへ、会話履歴を渡さず、スキル・SKILL.md・他の実装を読まない／適用しない条件で依頼。通常の判断で丁寧に制作するよう指定し、意図的な品質低下は依頼していません。エージェントからこの条件を守った旨の報告を受けています。

適用版はUIUX-controlの本文・UX方針を参照。ゲーム側は補助のゲームUI指針も参照しています。両側は同じ要件からの独立した制作案なので、色・配置・表現が異なります。スキル単独の因果効果や、他モデル・別タスクへの一般化を示す実験ではありません。

未使用版の納品後はファイルのハッシュを記録し、見た目の事後改変をしていません。比較画像はデスクトップ1440×1000相当、スマホ390×844相当。デスクトップはページ全体、スマホは初期表示範囲を撮影しています。各実装が選んだ既定の原稿表示倍率を使っており、同じ倍率の効果比較ではありません。

## 共通要件

| 題材 | 両版に含める要素 |
|---|---|
| 漫画 | 共通SVG、3ページ、3レイヤー、原稿名、拡大縮小・移動、プレビュー切替、濃度30%・線数60lpi相当・角度45度・コントラスト100%、プリセット、取り消し、初期化、PNG/TIFF・現在/全ページの出力設定 |
| ゲーム | 共通の月面描画、距離378m/目標600m、シールド2/3、エネルギー68%、鉱石12/20、コンボ×3、チェックポイント400m、2ミッション、修復1・ブースト2、ジャンプ、停止、設定、ヘルプ、結果と再挑戦 |

## 操作確認

- 漫画両版：濃度変更、プレビュー切替、取り消し、書き出し確認。
- 漫画適用版：125%表示を保持したまま濃度31→プレビューオフ/オン→取り消し30を確認。手動変更のプリセット表示をカスタムへ同期。
- 漫画適用版のスマホ：ページ自体をスクロールせず、原稿と4設定を表示。書き出しタブへ切替可能。
- ゲーム両版：修復後シールド3/3・残数0、ブースト後88%・残数1を確認。
- ゲーム両版：停止・結果状態を確認。適用版は結果表示中にHUDと操作を隠し、原因・スコア・再挑戦を表示。
- ゲーム適用版のスマホ：ジャンプボタンが初期表示内に収まり、結果と再挑戦も表示内で確認。
- 新規JS構文、ファイル参照、サンプル素材の一致、未使用版ファイルの保持を確認。

## 制限

- 漫画は固定サンプルのCSS近似。画像処理、読込、実保存はありません。ページは同じ絵を流用しています。
- ゲームは固定サンプル状態。ジャンプ演出・装備・画面遷移だけ操作でき、移動・衝突・音声・記録保存はありません。
- 実機、Safari、スクリーンリーダー、長時間利用、利用者の理解度や負担の測定は未実施。
- 不具合がない保証ではなく、構成と操作の違いを試すための例です。

## 状態をまたぐ操作の追加確認

漫画適用版について、以下を修正・再確認しました（未使用版は変更していません）。

- PNG確認後にTIFFや対象範囲を変えると、古い確認文を消す。
- トーンレイヤー非表示時は調整欄で理由を示し、その場で表示に戻せる。
- 値が変わらない初期化やスライダー操作を取り消し履歴に入れない。濃度31→初期化→初期化→取り消しで31へ戻る。
- スマホのスライダー要素高を44pxへ拡大。390×844相当で原稿領域を残し、ページ全体の縦スクロールなしを確認。実機でのタップしやすさは未測定。

適用版に追加修正が入っているため、従来の2版比較は修正機会も同一ではありません。より条件を揃えた4条件の探索比較はexperiments/game-four-conditionsを参照してください。
